# Snipora

One-page portfolio for Snipora, a short-form clipping brand. Plain HTML, CSS, and JS. No build step. GitHub Pages serves `index.html` from the root of `main`.

## Enable GitHub Pages

If the site is not on yet:

1. Open **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**.
4. Save.

Channel stats load from `data/channels.json`.

The Main YouTube (Collectibles) entry stays anonymous. Do not add a public name, handle, or URL for that channel.
